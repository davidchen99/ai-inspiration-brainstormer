# AI 灵感脑暴器

一个本地网页工具，用来把一句想法快速发散成多个内容选题，再继续扩写为公众号或小红书内容方案。

## 文件

- `plus index.html`：主工具页面，双击打开即可使用。
- `index.html`：跳转到主工具页面，保留给习惯打开 `index.html` 的入口。
- `sync-to-lark.ps1`：旧版飞书同步脚本，当前新版主流程暂未接入页面。

## 主流程

1. 输入一句想法、名称或几个关键词。
2. 默认生成 10 个脑暴点子。
3. 勾选有潜力的点子。
4. 点击“继续发散”，为每个已选点子生成 150 字以内内容介绍。
5. 按需点击“转公众号方案”或“转小红书方案”。
6. 复制已选内容，或导出 Excel / 批量 Word 压缩包。

## 公众号方案字段

- 公众号标题
- 一句话摘要
- 文章核心观点
- 文章大纲
- 开头切入方式
- 适合配图建议 3 张
- 目标读者
- 写作口吻
- 默认字数 1000 字，可在页面修改

## 小红书方案字段

- 小红书标题
- 150 字以内正文
- 3 张图片创意构思
- 标签
- 评论区引导

## AI 接入

当前版本真实接入 DeepSeek。

在页面的“高级设置”里填写：

- DeepSeek API Key
- 接口地址，默认 `https://api.deepseek.com/chat/completions`
- 模型，默认 `deepseek-chat`

如果没有填写 API Key，页面会生成可复制提示词，可以手动粘贴到 DeepSeek 或其他 AI 对话中使用。

## 导出

页面通过 CDN 引入以下前端库：

- `docx`：生成 `.docx`
- `xlsx`：生成 `.xlsx`
- `JSZip`：打包 `.zip`

导出规则：

- “导出 Excel”：导出已选点子的总览表。
- “批量导出 Word”：生成压缩包，里面包含总览 Excel、脑暴点子 Word、公众号方案 Word、小红书方案 Word。
